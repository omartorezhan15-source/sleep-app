# Luna — приложение для режима сна

Expo (React Native) приложение для iPhone и Android, которое помогает ложиться и вставать в одно и то же время.

- [research.md](research.md) — научная база (что доказано, что нет).
- [PLAN.md](PLAN.md) — функции, экраны, дизайн.

## Что есть в MVP

- Онбординг из 4 экранов: цели, возраст и круговой циферблат сна, план «если… то…», напоминания.
- Главный экран: луна-серия (растёт за ночи вовремя, убывает за пропуски, но не обнуляется), время до сна, план, факт дня. Утром — палитра рассвета.
- Отход ко сну: тёмный экран, шаги по одному, кнопка с удержанием «Я в кровати».
- Ночь и утро: «Спокойной ночи» → «Доброе утро», итог ночи и рост луны.
- Напоминания за 60, 30, 10 минут и в момент сна + утреннее.
- Статистика за неделю и месяц, настройки, русский и английский.

Блокировка приложений и будильник с заданием — этап 2 (нужен development build).

## Запуск на iPhone через Expo Go

Нужен компьютер (Mac, Windows или Linux) с [Node.js](https://nodejs.org) 20+ и iPhone с приложением **Expo Go** из App Store.

```bash
git clone https://github.com/omartorezhan15-source/sleep-app.git
cd sleep-app
git checkout claude/sleep-schedule-expo-app-f6nyyn   # пока MVP не влит в main
npm install
npx expo start
```

1. В терминале появится QR-код.
2. Открой камеру iPhone и наведи на QR-код → «Открыть в Expo Go».
3. Если телефон и компьютер в разных сетях (или QR не открывается) — запусти `npx expo start --tunnel`.

Проект на Expo SDK 58: версия Expo Go из App Store должна поддерживать SDK 58 (это текущая версия).
В Expo Go работают локальные уведомления; в вебе (`npx expo start --web`) уведомлений и вибрации нет.
